# 🏎️ APEX VELOCITY 4K - Ultimate 3D Hypercar Racer

An ultra-high-fidelity 3D car racing game built with **Three.js**, **WebGL**, **PBR Shading**, and the **Web Audio API**.

---

## 🌟 Game Highlights

- **4K High-DPI Visuals**: Metallic car paint with clearcoat specular reflections, carbon-fiber GT spoilers and splitters, glowing neon city skyline, wet reflective tarmac, projector LED headlights, and dual exhaust nitro fire.
- **Multiple Dynamic Camera Angles** (`C` key):
  - **Dynamic Chase Cam**: Spring-damped tracking with speed-reactive FOV warp.
  - **Cockpit / Hood Cam**: Immersive front-view velocity sensation.
  - **Bumper Cam**: Asphalt-scraping perspective.
  - **Helicopter Drone Cam**: Panoramic aerial perspective.
- **100% Procedural Web Audio Engine**:
  - Pitch-shifted dual-oscillator FM engine rumble that revs from 900 to 9000 RPM.
  - Gear shift pops and backfire effects.
  - Tire screeching on power drifts.
  - Deep bass nitrous oxide explosion.
  - Dynamic procedural synthwave racing soundtrack.
- **Intelligent AI Competitors**:
  - 5 rival hypercars (PHANTOM-V8, VIPER-GT, NEXUS-TURBO, KRONOS-9, TITAN-HYPER) with dynamic lane positioning and drafting.
- **Garage Customization**:
  - 7 Hypercar Paint finishes (Cyber Cyan, Crimson Red, Stealth Carbon, Electric Gold, Hyper Violet, Acid Green, Alpine White).
  - 5 Neon Chassis Underglow colors.

## 🎮 Driving Controls

| Action | Keyboard Controls |
| :--- | :--- |
| **Throttle / Accelerate** | `W` or `↑` (Arrow Up) |

| **Steering** | `A` / `D` or `←` / `→` (Left / Right) |
| **Handbrake Power Drift** | `Spacebar` |
| **Nitrous Oxide Boost** | `Shift` or `N` |
| **Switch Camera View** | `C` |
| **Reset Car Position** | `R` |
| **Toggle Audio** | `M` |
| **Pause Menu** | `Escape` |
